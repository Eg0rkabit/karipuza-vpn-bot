# Karipaza Froxy for Android

Android-клиент Karipaza Froxy с системным VPN на базе sing-box.

Первая тестовая версия включает:

- вход через подтверждение в Telegram без отдельного пароля;
- защищённую загрузку личной sing-box-конфигурации;
- хранение токена приложения в Android Keystore;
- подключение и отключение системного VPN;
- просмотр срока и расхода трафика;
- подготовленный экран тарифов без активной оплаты.

## Сборка

`libbox.aar` собирается из официального sing-box в GitHub Actions. После этого
собирается вариант `otherDebug`. Готовый APK публикуется как артефакт workflow.

Платёжный провайдер намеренно не встроен. Platega будет подключена отдельным
этапом после получения договора, API-документации и тестовых ключей.
